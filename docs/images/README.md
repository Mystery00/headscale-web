# Screenshot contribution guide

The public README gallery uses these sanitized screenshots:

- `dashboard.png`
- `users.png`
- `nodes.png`
- `routes.png`
- `preauth-keys.png`
- `settings.png`

Before replacing or adding an image, remove or replace hostnames, IP addresses, user names, email addresses, node names, API keys, tokens, IDs, and other private data. Prefer PNG or WebP images with a reasonable display width. Do not include browser bookmarks, personal notifications, extension overlays, or unrelated account information.
