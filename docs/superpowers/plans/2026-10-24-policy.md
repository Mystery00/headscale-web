# 访问策略实现计划

> 使用 executing-plans 在当前会话连续执行；用户已要求按批准的草图继续实现。

**目标：** 实现可视化表单与 HuJSON 共存的策略查看、编辑、校验及受控发布。
**架构：** 原始文本作为草稿，jsonc-parser 按路径修改；独立 repository 和工作台状态负责网络流程，元数据驱动字段表单。
**技术：** Vue 3、TypeScript、Naive UI、jsonc-parser、Vitest、Playwright。
**设计：** [设计文档](../specs/2026-10-24-policy-design.md)。

## 全局约束

- 中文文档与注释，英文日志，中英文界面。
- 不修改真实环境的策略，所有写入验证使用模拟服务。
- 不推送或合并本次实现；不改变已有真实连接配置。

## 审查重点

1. 未定义与空规则的语义差异：模型测试。
2. 注释、未知嵌套字段、重复属性与损坏文本：模型测试。
3. 校验期间修改文本、请求失败与旧结果：状态测试。
4. 服务器并发更新与确认后变更：状态及组件测试。
5. 加载失败、草稿离开及导出：组件和浏览器测试。
