# 访问策略工作台

用户已批准草图布局并要求继续实现。保留现有 Vue、Naive UI、中英文和纯静态架构；本次不连接生产环境进行写入，不迁移服务器存储模式。

## 行为

- `/policy` 页面提供概览、可视化配置、HuJSON 文本和变更预览。以原始文本作为唯一草稿，视图切换不重写内容。表单按路径修改，保留未知字段及未触及的注释；删除内容会删除其内部注释。所有改动先进入内存草稿，无自动保存。
- 覆盖 0.29.6 的 groups、hosts、tagOwners、acls（action/proto/src/dst）、grants（src/dst/ip/app/via）、ssh（action/src/dst/users/checkPeriod/acceptEnv）、nodeAttrs（target/attr/ipPool）、autoApprovers（routes/exitNode）、tests（src/proto/accept/deny）、sshTests（src/dst/accept/deny/check）、randomizeClientPort。动态 app capability 内容使用嵌套 JSON 编辑框，其他字段使用字符串、列表或选择控件。未知字段保留在文本中。
- 显式区分未定义、空数组、空对象和 false。不自动填默认规则，不进行 ACL 到 Grants 的隐式转换。不识别的结构不强行转换，提示转文本编辑。
- 文本支持注释、尾逗号，显示语法错误位置；重复属性禁止表单编辑与发布以免歧义。无效文本仍可导出；未知语义由服务器检查。
- GET 读取、POST check 校验、PUT 保存通过既有认证 HTTP。API 无存储能力查询，默认仅编辑/导出，提供显式“服务器已使用数据库存储”确认选择以启用发布流程；明确这不是切换服务器配置。file 模式拒绝写入时显示原始原因，保留草稿。
- 校验结果只绑定当时文本，修改立即失效。保存须通过校验并进入差异页，再确认发布。发布前 GET 比较基线文本与更新时间；冲突中止、保留草稿，允许导出后明确重新加载。无法完全消除 GET/PUT 间竞态，页面说明限制。失败不自动重试 PUT。发布成功再读取服务器状态；读回失败不冒充已同步。
- 加载失败不可创建空草稿覆盖。重新加载、路由离开与关闭窗口时保护未保存草稿。草稿不持久化，不携带到其他连接。

## 验证

单元测试覆盖文本无损修改、空值语义、异常解析、请求合同；组件测试覆盖校验失效、并发冲突、保存确认和失败保留；Playwright 与内置浏览器只连接独立模拟服务，覆盖分区表单、文本同步和发布。运行现有完整测试、lint、类型检查和构建，独立代码审查。不执行真实策略写入。

## 实现判断

使用 jsonc-parser 解析与路径编辑，原生多行文本框首版提供可靠编辑与行号错误，不引入大型 IDE。保留未修改文本，路径变更后再次解析确保有效。按字段元数据生成一致表单，动态映射与数组通过独立组件管理。上述实现细节由开发者选定。
